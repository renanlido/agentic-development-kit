# Contexto do Produto

Produto: Agentic Development Kit

Descrição:
Framework CLI-first para desenvolvimento assistido por IA,
automatizando discovery, PRD, planejamento, execução assistida,
code review, QA e PRs.

Público:

- Desenvolvedores de software
- Tech leads

Estado atual:

- Autopilot funcional porém frágil
- Alto consumo de tokens
- Baixa assertividade contextual
- Spawn excessivo de processos locais

Objetivo:

- Reconstrução em Python
- Alta testabilidade
- Execução previsível
- Uso disciplinado de técnicas avançadas de prompting
- Redução agressiva de tokens
